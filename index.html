Density of Homicides in Chicago

This project explored how homicide incidents are distributed across Chicago and highlighted areas with the highest concentrations. Instead of showing every incident as an individual point, I used density analysis to reveal broader patterns across the city. The map shows that homicides are not evenly distributed, with some neighborhoods experiencing much higher densities than others. This project demonstrates how GIS can be used to organize data and identify important spatial patterns.

GIS Tools and Skills

  • Density analysis
  • Working with point data
  • Data classification
  • Layer symbology
  • Map layout and visual hierarchy

Hispanic Population Distribution in the United States

This project explored how the Hispanic population is distributed across the United States. I used a dot-density map to represent population totals and make areas of concentration easier to identify. The map shows especially large concentrations in the Southwest, Florida, and several major metropolitan areas in the Northeast and Midwest. It also demonstrates how population totals can create a different geographic pattern than percentages alone. This project helped me understand how the choice of mapping method can influence the story communicated to the viewer.

GIS Tools and Skills

  • Working with U.S. Census data
  • Joining tabular and spatial data
  • Dot-density mapping
  • Attribute selection
  • Data classification and symbology
  • Map layout and visual hierarchy

Philadelphia Site-Selection Analysis

This project used GIS to identify areas in Philadelphia that met several site-selection requirements. I compared multiple geographic layers and used spatial analysis to gradually narrow the study area to the strongest candidate locations. After combining the required conditions, I separated the resulting polygons and identified the largest continuous candidate area. The final map shows how GIS can support planning decisions by turning several location-based criteria into a clear visual result.

GIS Tools and Skills

  • Site-selection analysis
  • Select by Location and Select by Attributes
  • Buffer and overlay analysis
  • Dissolve
  • Multipart to Singlepart
  • Area calculation and candidate comparison
  • Layer symbology and visual hierarchy
